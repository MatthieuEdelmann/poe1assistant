# Maps and league items

Apply the [shared pricing method](../pricing.md). Mercenary Warrants have their own
[category sheet](mercenaries.md).

- For maps, match the actual base, map tier, current Atlas series and unique/normal/rare
  state. Verify current trade types; historical map names need not remain separate items.
- For valuable rare or corrupted maps, inspect the requested modifier combination, pack
  size, reward-related properties and any special encounter rather than using the base quote.
- Invitations, beasts, corpses and wombgifts may have dedicated poe.ninja categories.
  Query the relevant category, check its coverage and match variants before using the quote.
- For logbooks, contracts and blueprints, identify area level, encounter/faction or job
  details, reward objective and revealed content. Confirm available filters from current
  trade metadata and inspect any unfilterable property directly in fetched listings.
- Separate an item's generic floor from premiums tied to specific content or rewards.
  If an important property cannot be searched, label the resulting sample as broader than
  the actual item and retain the uncertainty in the estimate.

Use [bulk](bulk.md) for stackable fragments and consumables. Recheck league changes before
assuming that a prior category, map layout or reward source still exists.
