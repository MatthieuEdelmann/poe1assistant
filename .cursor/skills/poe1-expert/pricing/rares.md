# Rare and magic items

Apply the [shared pricing method](../pricing.md). This covers equipment, ordinary jewels,
abyss jewels and flasks; route unique jewels to [uniques](uniques.md).

- Select the stats buyers need for the slot: life, ES, resistance totals, suppression,
  movement speed, attributes, gem levels, damage, speed or damage-over-time multipliers.
  Distinguish local weapon/armour modifiers from global ones. Weak unrelated modifiers
  need not constrain the comparison.
- Resolve current pseudo stats for combined totals, so implicit, explicit and crafted
  contributions are compared consistently. For weapons, compare relevant physical,
  elemental or total DPS rather than raw modifier counts.
- Start with nearby rolls if exact matches are scarce. An 85–90% threshold can be an
  exploratory starting point, not proof that a weaker item is worth the same amount.
  Inspect actual fetched rolls and tighten the final comparison where possible.
- Test meaningful combinations together. A jewel with three synergistic modifiers is
  not valued by adding three individual modifier prices. Use a `count` group when the
  buyer accepts several alternative useful modifiers.
- Check crafting value separately: an open prefix/suffix, useful fracture, influence or
  strong base can matter. Verify a proposed bench craft's current availability, item-level
  requirement, mod group and free affix before treating it as an upgrade.
- Corruption or mirroring can remove crafting options. Assess restrictions before comparing
  to an otherwise similar craftable item. For flasks, match base, utility rolls and enchant.

Do not reuse old claims that ordinary jewels or a particular rare slot are always cheap.
Use [bases](bases.md) when the unfinished crafting base is the main source of value.
